# GNSSpy v3 Release Notes

## v3.0.0

GNSSpy v3.0.0 introduces a function-based package hierarchy for multi-GNSS workflows.

Main package namespaces:

- `gnsspy.data_access`
- `gnsspy.io`
- `gnsspy.orbit`
- `gnsspy.atmosphere`
- `gnsspy.positioning`
- `gnsspy.quality`
- `gnsspy.geodesy`
- `gnsspy.visualization`
- `gnsspy.cli`
- `gnsspy.workflows`
